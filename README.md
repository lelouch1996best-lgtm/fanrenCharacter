# fanrenCharacter

《凡人修仙传》二创人物设定图集，按角色分文件夹整理，包含人物三视图、特写图与详细信息图，用于短剧/视频二创的角色形象参考。

## 目录结构

每个角色一个文件夹，常见图片类型：

- `人物三视图（基础/敦煌/球队/白礼服/校服等）.png`：角色多视角设定图
- `特写图.png` / `特写.png`：角色面部特写
- `详细信息图.png`：角色设定信息图
- 其他特殊形态图（如 `银月兽形态.png`、`风雷翅.png`）
